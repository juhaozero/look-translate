# 产品决策（已锁定）

> 平台：Windows 优先；macOS 暂不考虑  
> 不做：AI 翻译、账号、同步、背单词、历史面板、UIA 取词

## 定位

- **主路径**：划词翻译（选中文本 → 在线引擎译文）
- **补充**：离线 MDict 词库（仅短词）
- **后期**：本地 OCR（独立快捷键）

## 决策表

| 主题       | 选择                                                                |
| ---------- | ------------------------------------------------------------------- |
| 产品主路径 | 划词翻译优先，词库作补充                                            |
| 取词       | 剪贴板模拟（备份→Ctrl+C→读取→还原）；失败不自动走 OCR               |
| OCR        | 独立快捷键 → 框选；引擎可切换：系统 OCR / Tesseract.js；互不兜底 |
| 技术栈     | Tauri 2 + Rust + React                                              |
| 翻译引擎   | 多引擎可并行启用（`engine.actives`）；可填 Key；默认微软；可选 `microsoft_web` / `google` / `google_web` / `cloudflare`；新厂商用 `[engines.<id>]` Config-driven（ADR 0001）；浮层按引擎分块展示 |
| 语言       | 源语言 auto，默认目标语 `zh-CN`（Google 风格；兼容旧 `zh-Hans`）；设置可改；浮层可改目标语并重译 |
| 词库格式   | MVP 仅 MDict；`DictionaryProvider` 预留扩展                         |
| 推荐词库   | ECDICT mdx（headless）按需下载至 `data/dicts/ecdict.mdx`，不预装安装包 |
| 短词规则   | ≤30 字符 **且** ≤3 token，且无换行 → 才查词库                       |
| 多词典     | 只查「当前启用列表中的第一本」                                      |
| 词条展示   | MVP 纯文本；以后可升受限 HTML                                       |
| 浮层       | 光标附近；Esc/点外关闭；一键复制译文；可改目标语重译                |
| 托盘       | 最小托盘（设置 / 启用热键 / 退出）；默认可改键 `Ctrl+Shift+D`       |
| 缓存       | 内存 LRU 100 条；失败时短词可回落词库                               |
| 代理       | 跟随系统代理                                                        |
| 数据目录   | 安装目录旁 `data/`（便携配置）                                      |
| 发布       | NSIS（推荐，当前用户）+ MSI；卸载可询问备份/删除 `data/`；见 `docs/packaging.md` |

## 明确不做

- AI / LLM 翻译
- 账号、云同步、背单词、复习
- 翻译历史面板 / 持久化历史库
- macOS（本期）
- UI Automation 取词
- `.mdd` 资源（图片/音频）加载
