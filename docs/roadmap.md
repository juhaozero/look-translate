# 路线图与开发顺序

## Phase 1 — MVP（先做）

目标：Windows 上可用的划词翻译 + 可选 MDict 补充。

| 顺序 | 任务 | 说明 |
|---|---|---|
| 1 | 脚手架 ✅ | Tauri 2 + React；托盘；双窗口（popup/settings）骨架 |
| 2 | 配置 ✅ | `data/config.toml`；安装目录旁便携目录约定 |
| 3 | 热键 ✅ | 全局 `Ctrl+Shift+D`；可改；可总开关 |
| 4 | 剪贴板取词 ✅ | 备份/还原；空文本处理 |
| 5 | 翻译抽象 + 微软引擎 ✅ | Key 可配；auto→zh-Hans；系统代理 |
| 6 | 浮层 ✅ | 光标附近、加载态、复制、改目标语重译、Esc/失焦关闭 |
| 7 | LRU ✅ | 内存 100 条 |
| 8 | MDict | 文件夹/路径引用；短词规则；只查第一本；纯文本 |
| 9 | 设置页 | 引擎、Key、热键、词典、目标语 |
| 10 | 安装包 | NSIS 或 MSI；说明 `data/` 位置与卸载策略 |

**Phase 1 验收**

- [ ] 任意可选中文本的应用中，快捷键弹出译文
- [ ] 浮层可复制、可改目标语重译
- [ ] 填入微软 Key 后稳定翻译；跟随系统代理
- [ ] 导入一本 MDict 后，单词可在译文下看到纯文本释义
- [ ] 长句不查词库；断网时长句报错、短词可仅词库
- [ ] 安装包可安装/卸载；配置落在安装目录旁 `data/`

## Phase 2 — 本地 OCR

| 任务 | 说明 |
|---|---|
| 独立 OCR 热键 | 默认 `Ctrl+Shift+S`，可改 |
| 截屏 | 指针附近固定矩形 |
| 识别 | Windows.Media.Ocr |
| 接入同一流水线 | OCR 文本 → translate + 短词词典 |

## Phase 3 — 增强（可选，非必须）

- 更多翻译引擎（含可选 Google，需标注稳定性风险）
- 词条受限 HTML 渲染
- 便携 ZIP 发行通道
- 剪贴板失败时的体验优化（提示用户用 OCR 键）

## 非目标（持续有效）

AI 翻译、账号同步、背单词、历史库、macOS、UIA 取词。
